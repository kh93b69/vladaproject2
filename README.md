# MeetMates 🧭

Интерактивный mobile-first MVP-прототип сервиса для поиска локальных людей, маршрутов и гидов в новом городе.

> Весь интерфейс — на русском языке. Карта на экране «Детали маршрута» — настоящая интерактивная карта (OpenStreetMap + Leaflet): её можно двигать и масштабировать.

## Стек

- **React 18** (функциональные компоненты + хуки)
- **Vite** — сборка и dev-сервер
- **Tailwind CSS** — стилизация (mobile-first)
- **framer-motion** — плавные переходы между экранами
- **lucide-react** — иконки
- **react-leaflet / leaflet** — настоящая интерактивная карта (OpenStreetMap)

## Флоу (6 экранов)

0. **Сплэш** — «Путешествуй вместе с MeetMates», карта на фоне, кнопка «Погнали».
1. **Выбор города** — табы «город / страна», поиск, популярные направления.
2. **Выбор интересов** — цветные карточки категорий.
3. **Подбор маршрутов** — анимация загрузки → список рекомендованных маршрутов.
4. **Детали маршрута** — интерактивная карта Leaflet с маркерами + таймлайн точек.
5. **Успех** — маршрут сохранён.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Сборка

```bash
npm run build
npm run start   # vite preview на 0.0.0.0:$PORT
```

## Деплой на Railway

Проект готов к деплою на [Railway](https://railway.app):

1. Создайте новый проект из этого GitHub-репозитория.
2. Railway автоматически использует `nixpacks.toml`:
   - сборка: `npm run build`
   - запуск: `npm run start`
3. `PORT` Railway пробрасывает автоматически — приложение его подхватывает.

Дополнительные переменные окружения не нужны.
